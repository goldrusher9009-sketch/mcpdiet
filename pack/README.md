# mcp-pack

Small, keyless MCP connectors. Each runs as a CLI (`node dist/src/<name>.js <path>`) or as a stdio MCP server (`... serve`).

repo-weigh, envguard, cronwise, license-check, dockerfile-doctor, gha-doctor, csv-profile, takeoff, log-triage, openapi-slim, regex-lab, prompt-lint, tz-planner, bid-total.

`npm install && npm run build && npm test`
